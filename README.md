# Top Journal 0.26.0

Неофициальный Android-клиент для journal.top-academy.ru. Проект не связан с владельцами платформы и предназначен для личного и учебного использования.

## Новые нативные экраны

- Задания: отдельные категории «Текущие», «На проверке», «Проверено», «Просрочено», переключение страниц, сроки, преподаватель, подробности и ссылка на файл.
- Материалы: уроки, книги, видео, статьи, практика, тесты и презентации; фильтр методических и рекомендованных материалов; отдельные карточки и состояния пустой библиотеки.
- Объявления: последние сообщения с датами; полный текст раскрывается внутри нативной карточки, ссылки открываются по нажатию.
- Награды: полученные и будущие достижения, фильтры и реальные начисления. Названия берутся из словаря дневника; если перевод недоступен, показывается номер достижения.
- Отзывы преподавателей: предмет, автор, дата и текст; отдельное состояние для отсутствующих отзывов.

Белые поверхности, чёрные акценты, крупные скругления, нативная прокрутка, фильтры, анимации нажатия и появления. Основные четыре вкладки и перечисленные дополнительные разделы больше не требуют перехода по меню сайта. При открытии дополнительных нативных экранов активна вкладка «Ещё».

Оплата, профиль, FAQ, контакты, обращения, жалобы и магазин остаются гибридными. Интерактивные материалы без прямой ссылки также открываются внутри сайта; внешние ссылки и файлы — через подходящее приложение. Нативная отправка выполненного задания в этой версии не добавлена.

## Запуск, вход и восстановление

- При запуске сразу создаётся нативный экран. До получения данных видны заголовки и skeleton-блоки, а не исходный сайт.
- Сохранённая настройка оригинального оформления больше не отключает нативные экраны; она относится к оставшимся веб-страницам.
- Авторизация подтверждается успешным ответом профиля для текущего заголовка авторизации. Наличие токена или аватара само по себе не считается подтверждением.
- После 401 предусмотрена пауза на штатное обновление сессии, затем один автоматический переход на вход. При отсутствии наблюдаемого заголовка авторизации переход возможен после 25 секунд ожидания. Автоматический переход ограничен одним за запуск Activity.
- 403 и сетевые сбои не считаются доказательством выхода. Для сетевых ошибок проверки профиля разрешены максимум три попытки с паузами; для обычных данных — одна дополнительная попытка. Автоматические повторы после 401/403 не выполняются.
- Форма входа показывается после появления поля пароля; до этого сохраняется нативный экран загрузки с возможностью повторить или открыть вход. Переход на маршрут входа очищает данные прежнего аккаунта, сохраняя в памяти уже наблюдаемый заголовок только для повторной проверки.
- Исправлено определение текущего раздела во время входа: маршрут авторизации больше не переводит приложение в «Ещё» с исходной страницей сайта.
- Для гибридных переходов добавлен нативный экран ожидания и состояние ошибки соединения. После двух быстрых аварий WebView автоматический перезапуск останавливается и появляется явная кнопка восстановления.
- Ошибка загрузки аватара больше не запоминается как успешная загрузка; повтор возможен с паузой 30 секунд. Ответ старой сессии не устанавливает изображение в новую.

## Кэш и загрузка

Данные экранов сохраняются в приватном хранилище приложения и восстанавливаются при следующем запуске. Срок хранения отображаемых полей — до 30 дней; подпись показывает время сохранения. Кэш появляется первым, обновление выполняется в фоне. При ошибке успешно загруженные поля не стираются. Успешный пустой ответ отличается от отсутствующего ответа.

Категории и страницы заданий, а также типы материалов сохраняются раздельно. Ответ на прежний фильтр не подменяет новый; после завершения выполняется запрос последнего выбранного фильтра. Полный текст объявления сохраняется по его идентификатору.

Skeleton зависит от состояния запроса, а не от трёхсекундного таймера. При окончательной ошибке анимация завершается, остаются структура экрана, сохранённые значения и понятный статус с повтором. Неизвестные значения не заменяются нулями. Кэш очищается при переходе на вход и смене аккаунта.

Заголовок авторизации остаётся в памяти JavaScript WebView; не передаётся в Java, не сохраняется в кэш и не включается в диагностику.

## AI-анализ домашних заданий

AI-функции работают через локальный HTTPS-сервер на компьютере: ключ провайдера не включается в APK и не хранится в репозитории. Сервер умеет кратко разбирать отдельное задание, составлять план, объяснять требования и анализировать прикреплённые PPTX, DOCX, XLSX, PDF и изображения.

Перед сборкой с AI запустите `server/setup.ps1`, затем пересоберите приложение. Скрипт локально создаст конфигурацию, сертификаты и DPAPI-защищённый файл токена; все эти файлы исключены из Git. Подробности находятся в [`server/README.md`](server/README.md).

## Установка и проверка на телефоне

Собрать debug APK и установить его на устройство. Из-за нейтрального публичного application ID эта сборка устанавливается отдельно от прежних персональных тестовых сборок.

1. Запустить приложение: сразу должен появиться нативный экран с кэшем или skeleton-блоками. При необходимости дождаться формы входа и войти.
2. Проверить главную и четыре нижние вкладки, затем материалы, объявления, награды и отзывы через «Ещё».
3. Быстро сменить несколько фильтров заданий и материалов: должен остаться последний выбранный фильтр.
4. Раскрыть объявление и проверить полный текст.
5. После успешной загрузки закрыть приложение, отключить сеть и открыть снова: сохранённые страницы должны остаться доступны.
6. При повторной ошибке открыть «Диагностика загрузки» и скопировать отчёт. Там видны HTTP-коды, наличие заголовка и результат проверки профиля, но нет паролей, токенов и содержимого ответов.

## Что проверено в среде разработки

- Сборка APK, Android Lint и 10 Java-тестов проходят.
- 39 JavaScript-тестов проходят: ожидание реального ответа, ограничение повторов, 401/403, обновление токена, переход на вход, фильтры, реальные схемы новых разделов, частичный кэш и изоляция запоздавших ответов.
- Модели и пути запросов сверены с публичным JavaScript-кодом сайта, сохранённым для исследования. Сами автоматические тесты используют искусственные ответы.
- Физического устройства и Android-эмулятора нет. Авторизованные запросы с аккаунтом пользователя, внешний вид и взаимодействие на телефоне этой сборки ещё не проверены. Успешная сборка не подтверждает устранение всех ошибок реального сервера.

## Сборка исходников

Java для Android-компонентов, JavaScript для сессии и запросов внутри WebView, CSS для гибридных страниц, XML для ресурсов, Groovy для Gradle.

Нужны JDK 17+, Android SDK 35 и Node.js для JavaScript-тестов. Указать SDK через local.properties или ANDROID_HOME.

```powershell
.\gradlew.bat assembleDebug testDebugUnitTest lintDebug
node --test tests/journal-bridge.test.cjs
```

Параметры: app.topjournal.client, версия 0.26.0, versionCode 26, minSdk 26, targetSdk 35, AndroidX WebKit 1.17.0. APK подписывается локальным debug-ключом разработчика.
