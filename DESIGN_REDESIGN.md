# Top Journal 0.22 — Vercel redesign

## Тема

Интерфейс использует палитру [Vercel от Serafim](https://21st.dev/@serafimcloud/themes/vercel):

- background: `oklch(0.99 0 0)` → `#fcfcfc`;
- card: `oklch(1 0 0)` → `#ffffff`;
- primary: `oklch(0 0 0)` → `#000000`;
- secondary/accent: `oklch(0.94 0 0)` → `#f0f0f0`;
- muted: `oklch(0.97 0 0)` → `#f7f7f7`;
- border: `oklch(0.92 0 0)` → `#e5e5e5`;
- destructive: `#e5484d`;
- radius: `8 dp`;
- Geist-подобная системная sans-serif и monospace только для чисел и технических меток.

Notebook-разлиновка, песочный акцент и книжная serif-типографика удалены.

## Новая информационная архитектура

### Главная

Это dashboard, а не длинный набор одинаковых блоков:

1. Чёрный Task Control показывает активные, просроченные и проверяемые задания.
2. Баллы, топкоины и гемы вынесены из шапки в отдельную компактную строку.
3. Средний балл, посещаемость и позиции в рейтинге собраны в bento-сетку 2×2.
4. Экзамены и события представлены как компактные списки.
5. Второстепенный рейтинг лидеров убран с первого экрана.

### Расписание

Вместо семи последовательных карточек показывается один выбранный день:

- единый недельный переключатель из семи равных ячеек;
- количество занятий видно до открытия дня;
- под переключателем находится одна таблица выбранного дня;
- время, предмет, преподаватель и аудитория имеют постоянные колонки;
- пустой день отображается как самостоятельное состояние.

### Оценки

- крупная сводка периода на чёрной панели;
- посещения, пропуски и опоздания видны одновременно;
- оценки агрегируются по предметам;
- последние результаты отделены от предметной статистики.

### Задания

- экран оформлен как Task Inbox;
- фильтры стали сегментами с чёрным выбранным состоянием;
- задание — компактная строка, а не большая editorial-карточка;
- статус, срок, наличие файла и переход к подробностям читаются без раскрытия;
- пагинация вынесена в отдельную панель.

### Общая оболочка

- высота шапки уменьшена с 96 до 64 dp;
- балансы удалены из шапки;
- добавлен компактный знак продукта, заголовок раздела, уведомления и профиль;
- нижняя навигация больше не плавающая «капсула», а полноценная системная панель;
- нативные и встроенные веб-экраны используют один набор Vercel-токенов.

## Сохранённые возможности

Редизайн не меняет авторизацию, фоновое восстановление сессии, API-снимки, уведомления, reader PPTX/JPEG и отправку оценок преподавателю и занятию.
